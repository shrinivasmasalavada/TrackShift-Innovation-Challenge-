The **TrackShift Innovation Challenge** is a national-level innovation/hackathon program organized by the [Mphasis F1 Foundation](https://www.mphasis.com/home/corporate/community-social-responsibility.html?utm_source=chatgpt.com) with Plaksha University. It focuses on:

* AI
* Data Science
* Embedded Systems
* Simulation
* Mobility
* Robotics
* Smart infrastructure

The event is inspired by Formula 1 engineering and technology. ([Mphasis][1])
